## 核心转译

| 理论概念 | 日常实践含义 | 核心问题 | 防止误用 |
|---|---|---|---|
| 实事求是 | 事实、假设和价值判断分离 | 我们真正知道什么，来源是什么？ | 不把个人经验或权威表述当作事实 |
| 实践论 | 认识通过行动验证并反复修正 | 哪个最小试验能最快推翻错误判断？ | 不把“先做再说”当成无目标试错 |
| 矛盾普遍性与特殊性 | 使用通用框架，但按具体条件分析 | 这个场景与类似案例最关键的不同是什么？ | 不照搬成功案例或固定公式 |
| 主要矛盾 | 当前最制约全局的上游问题 | 解决哪个问题会释放最多后续环节？ | 不把最显眼、最紧急或最容易的问题自动当作主要矛盾 |
| 矛盾主要方面 | 当前更决定结果的一侧 | 哪一侧在现阶段主导结果，什么条件会使它变化？ | 不把阶段性判断永久化 |
| 内因与外因 | 建设内部能力，同时利用外部条件 | 如果外援消失，我们还能维持哪一部分闭环？ | 不否认政策、市场、环境等外部限制 |
| 群众路线 | 用户、执行者和受影响者共同参与认知闭环 | 一线经验如何进入决策，方案如何回到现场验证？ | 不用“多数”压制少数权利或专业风险 |
| 独立自主 | 掌握关键能力与选择权 | 哪些核心能力、数据或渠道不能完全外包？ | 不等于拒绝合作或重复造轮子 |
| 统一战线 | 围绕最小共同目标建立透明协作 | 各方在哪一点利益一致，差异如何被容纳？ | 不操纵、欺骗或用标签消除分歧 |
| 武装斗争（仅作中性转译） | 掌握合法、非暴力的执行能力和落地手段，使方案不止停留在主张 | 目标所需的人员、权限、工具、流程和资源是否真正到位？ | 绝不字面应用于日常事务，不鼓励暴力、胁迫、违法或对抗升级 |
| 分清敌我友 | 识别受益者、协作者、观望者、顾虑与阻塞条件 | 谁支持什么、担心什么、能贡献什么？ | 日常场景不把人定义为“敌人”；关注立场背后的条件和利益 |
| 根据地与农村包围城市 | 在有利的小范围建立可持续样板，再相邻扩展 | 哪里最适合形成低成本、可复用的成功闭环？ | 不把边缘试点的成功直接外推到全部场景 |
| 集中优势力量、各个解决 | 限制在制品，聚焦当前瓶颈 | 现在停止哪些事项，才能真正解决关键问题？ | 不忽略系统协同，也不把所有资源押在未经验证的单点上 |
| 积小胜为大胜 | 用阶段成果积累能力、证据和信任 | 最近一个可验证里程碑是什么？ | 小胜必须服务于总目标，避免忙碌替代进展 |
| 战略上坚定、战术上重视 | 对长期方向有信心，对具体风险保持严谨 | 哪些风险会让本阶段失败，如何提前验证？ | 不轻视竞争者、困难或专业细节 |
| 党的建设与整风 | 建立团队学习、表达、协作和纠偏机制 | 哪个机制让错误信息持续存在？ | 批评行为和机制，不搞人格审判或忠诚测试 |
| 为人民服务 | 用真实受益和公平影响约束方案 | 谁获益，谁承担成本，谁没有发言权？ | 不以宏大目标掩盖个体损害 |

## 组合使用

### 分析陌生事物

使用“实事求是 + 矛盾特殊性 + 主要矛盾”：先调查，再建立结构解释，最后找当前瓶颈。

### 制定资源有限的计划

使用“主要矛盾 + 独立自主 + 集中优势力量 + 积小胜”：保证最小闭环，把资源投入一个关键阶段结果。

### 推动多人协作

使用“群众路线 + 统一战线 + 整风”：收集一线经验，建立共同目标，设置透明反馈和纠偏机制。

### 高不确定性决策

使用“实践论 + 根据地/试点 + 阶段变化”：先验证高风险假设，根据结果重判主要矛盾。

### 项目复盘

使用“实践检验 + 批评与自我批评 + 矛盾转化”：检查认识错误和机制缺陷，避免只追责个人。

## 常见误用

1. **先有结论，再找事实**：违反实事求是。先列反证和未知项。
2. **任何问题都归结为人或立场**：忽略流程、激励、能力和环境。先分析系统条件。
3. **把紧急事项当主要矛盾**：紧急不等于上游。检查解决后的系统释放程度。
4. **无限调查，不进入实践**：认识需要行动检验。为关键未知设计有期限的小实验。
5. **一味依靠自己**：独立自主是保有选择权，不是拒绝专业合作。
6. **用共同目标压制异议**：异议可能揭示风险。记录保留意见并设计验证。
7. **全面铺开以显示决心**：证据不足时先做可逆试点，定义扩展门槛。
8. **只讲精神，不配资源**：行动必须有负责人、投入、依赖和完成证据。
9. **复盘变成检讨会**：围绕事实、决策过程和机制改进，不进行人格攻击。

## 经典来源索引

- 《反对本本主义》：调查研究、反对脱离实际的照搬。
- 《实践论》：实践与认识的循环、感性认识到理性认识再回到实践。
- 《矛盾论》：矛盾特殊性、主要矛盾、矛盾主要方面、内外因。
- 《关于领导方法的若干问题》：从群众中来，到群众中去。
- 《〈共产党人〉发刊词》：统一战线、武装斗争、党的建设的历史经验；日常使用时必须做中性转译。
- 《星星之火，可以燎原》及相关军事论述：建立局部基础、积累力量、由局部走向全局；日常使用时转译为试点和渐进扩展。
- 《改造我们的学习》《整顿党的作风》《反对党八股》：反对主观主义、宗派主义和空洞表达。
- 《为人民服务》：以人的实际利益作为价值检验。

此索引用于追溯思想来源，不表示把历史情境直接套用于当代组织、商业或个人关系。
